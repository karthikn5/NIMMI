# Nimmi AI Tutorial & Reference Video

This directory holds the official video walkthrough for the **Reference** section (`/dashboard/reference`).

## Target Video File Location
Save the final exported video as:
```
dashboard/public/videos/tutorial.mp4
```

## Recommended Video Specifications
- **Format:** MP4 (H.264 video, AAC audio)
- **Resolution:** 1920x1080 (1080p, 16:9)
- **Frame Rate:** 60 fps (or 30 fps)
- **Bitrate:** 8 - 10 Mbps
- **Target Duration:** ~4 to 5 minutes
